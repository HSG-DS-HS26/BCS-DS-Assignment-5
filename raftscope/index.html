Exercise

Create exercise freezes the paused simulation as the stage your partner has to reason about. Fill this in, press Set question and continue the run, run the simulation until the solution becomes visible, then press Export challenge: the exercise server saves the exercise as exercises/<name>.json in your repository, or downloads the JSON file if no server is running.

Pick an answer: the correct answer is highlighted. Then show the solution to watch the recorded run from the stage.
